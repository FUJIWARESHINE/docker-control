# CYBER NAV - 赛博朋克导航页

一个现代化的个人导航页面，采用赛博朋克风格设计，支持多种卡片类型、组件集成和响应式布局。

## ✨ 功能特性

### 🎴 多种卡片类型
- **普通卡片**：标准链接卡片，支持图标、颜色自定义
- **组件卡片**：集成 Emby/Jellyfin 媒体展示、系统监控等
- **容器卡片**：Docker 容器状态监控，实时显示运行状态和资源占用

### 📁 分组管理
- 支持创建多个分类分组
- 分组可设置公开/私有（私有分组在未登录时完全隐藏）
- 分组排序、图标自定义
- 侧边栏快速切换分组

### 🎨 个性化设置
- **主题色**：多种预设主题色可选
- **背景图**：支持上传自定义背景，电脑端和手机端可分别设置
- **随机背景**：可开启背景图随机切换
- **粒子效果**：可开关的动态粒子背景
- **站点信息**：自定义站点名称和 Logo

### 📱 响应式设计
- 完美适配电脑、平板、手机
- 手机端独立背景设置
- 智能设备检测（综合屏幕尺寸、UA、触摸屏等多种方式）

### 🔐 权限控制
- 支持登录/未登录两种状态
- 分组公开性优先级大于卡片设置
- 私有分组下的所有卡片对未登录用户不可见

### 📥 数据管理
- **导入书签**：支持从浏览器导出的 HTML 书签文件导入
- **导出数据**：一键导出所有分类和链接数据
- **图标获取**：自动从网站获取 favicon 图标
）

### 登录管理
点击右上角设置按钮，输入管理密码登录后可进行以下操作：
- 添加/编辑/删除链接
- 管理分类分组
- 上传背景图
- 修改站点设置

## 📋 卡片类型说明

### 普通卡片
最基础的链接卡片，包含：
- 名称
- 内网/公网地址
- 图标（自动获取或手动上传）
- 颜色
- 描述

### 组件卡片
集成第三方服务的动态卡片：

| 组件类型 | 功能 |
|---------|------|
| Emby | 显示最近观看的媒体 |
| Jellyfin | 显示最近观看的媒体 |
| 系统监控 | 显示 CPU、内存、磁盘使用率 |

### 容器卡片
Docker 容器监控卡片：
- 实时状态指示灯（运行中/已停止）
- CPU 和内存使用率
- 点击可跳转到容器管理页面

## ⚙️ 设置选项

### 外观设置
| 选项 | 说明 |
|------|------|
| 主题色 | 选择界面主色调 |
| 背景图 | 上传或选择背景图片 |
| 手机背景 | 单独设置手机端背景 |
| 随机背景 | 开启后定时切换背景 |
| 粒子效果 | 开关动态粒子背景 |

### 站点设置
| 选项 | 说明 |
|------|------|
| 站点名称 | 显示在页面顶部的标题 |
| 站点 Logo | 显示在标题旁的图标 |

### 组件设置
| 选项 | 说明 |
|------|------|
| 刷新间隔 | 组件数据自动刷新的时间间隔 |

## 🔧 技术特性

### 前端
- 纯原生 JavaScript，无框架依赖
- CSS 变量实现主题切换
- 毛玻璃效果（backdrop-filter）
- CSS Grid 响应式布局
- 动态粒子背景（Canvas）

### 后端
- Go + Gin 框架
- SQLite 数据库
- Docker API 集成
- 图标缓存机制

### 安全
- JWT 认证
- CSP 内容安全策略
- 跨域资源控制

## 📝 快捷操作

| 操作 | 说明 |
|------|------|
| 点击卡片 | 打开链接 |
| Ctrl+点击 | 新标签页打开 |
| 右键卡片 | 编辑/删除菜单 |
| 悬停长名称 | 自动滚动显示完整名称 |
| 点击侧边栏按钮 | 展开分组面板 |
| 搜索框 | 快速搜索链接 |

## 🎯 特色功能

### 智能图标获取
- 自动从目标网站解析 favicon
- 支持 apple-touch-icon、og:image 等多种图标
- 图标本地缓存，加速加载

### 书签导入
- 支持 Chrome/Firefox/Edge 导出的 HTML 书签
- 自动创建对应分组
- 后台异步获取图标（不阻塞导入）

### 网络切换
- 支持内网/公网地址切换
- 根据当前网络环境自动选择
